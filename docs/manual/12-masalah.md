# Pemecahan Masalah

| Masalah | Penyebab yang mungkin | Yang dilakukan |
| --- | --- | --- |
| Kiosk menulis "Belum ada jadwal di ruangan ini" | Di luar jam absen, hari libur, atau kelas belum punya ruangan | Periksa jam di Pengaturan, Hari Libur, dan ruangan kelas |
| Kiosk menulis "Perangkat belum terdaftar" | Perangkat belum dipasangkan atau data browser dihapus | Buat kode pasangan baru di Perangkat Scanner |
| Kiosk menulis "Perangkat ini dicabut" | Perangkat dicabut Super Admin | Pasangkan ulang bila memang perangkat sekolah |
| Scanner USB tidak mengetik apa pun | Kolom scanner tidak aktif | Klik kolom "Scanner USB" di kiosk, lalu scan lagi |
| Kamera tidak menyala | Alamat bukan HTTPS atau izin kamera ditolak | Pakai HTTPS, izinkan kamera di pengaturan browser, atau pakai scanner USB |
| Siswa "Bukan kelas ini" | Siswa scan di ruangan lain, atau anggota kelas salah | Periksa anggota kelas di halaman kelas |
| "Kartu tidak berlaku" untuk kartu baru | Kartu lama dicetak ulang setelah diganti | Cetak ulang dari Kartu QR (kode terbaru) |
| Angka antrean di kiosk tidak turun | Internet kiosk putus | Biarkan browser terbuka; antrean terkirim otomatis saat tersambung |
| Siswa tidak menjadi Alpa | Sesi belum ditutup atau scheduler mati | Lihat Kesehatan Sistem → Scheduler |
| WhatsApp tidak terkirim | Notifikasi mati, token salah, atau nomor kosong | Kirim pesan uji di Notifikasi WA, lihat pesan galatnya |
| Kesehatan "Cadangan harian" merah | Scheduler mati atau disk penuh | Periksa Scheduler dan Ruang disk, lalu Buat cadangan sekarang |
| Lupa password | | Minta Super Admin membuat password sementara |

## Meminta bantuan

Saat melapor, sertakan:

- **Halaman** yang dibuka (alamat di browser).
- **Waktu** kejadian dan **akun** yang dipakai.
- **Tangkapan layar** pesan galat.

Laporan bisa dikirim lewat menu **Kirim Masukan** agar tercatat.
